# /resume — старт сессии

Цель: за 1–2 минуты загрузить контекст и выдать пользователю чёткое резюме, чтобы он дал «да» на конкретный пункт работы.

## Шаги

1. **Контекст (только чтение).** Прочитай параллельно: `WORK.md` (главный источник правды), `docs/memory/INDEX.md`, 1–2 релевантных memory по теме активной задачи. НЕ читай весь репозиторий, `PLAN.md` целиком, `AGENTS.md` (он уже auto-loaded).
2. **Состояние репо.** `git status --short`, `git log --oneline -5`, `git branch --show-current`. Если есть Docker — `docker compose ps`.
3. **Резюме (макс. 6–8 строк):** где находимся (ветка, последний коммит, deployed-версия); активная задача из `WORK.md` и что нужно для продолжения; если активной нет — какой пункт очереди рекомендуешь; action items за пользователем; замеченные расхождения; подтверди, что прочитал `WORK.md` и правила.
4. **Жди явного «да»** на конкретный пункт перед стартом работы.

## Правила
- Не дублируй чтение — `WORK.md` + память достаточно.
- 8 строк — это не больше 8 строк.
- Не запускай тесты в `/resume`.
- Если git не инициализирован — пометь и переходи к резюме.
